# Campus Hollow

一个纯像素风的 **校园漫游** 游戏：整张地图按校园总平面图排布，没有农田。当前版本在打磨道路、铺装与整体校园质感。

用 **Godot 4.7+** 打开本文件夹即可运行（F5）。

## 本版调整

- **道路网络重排**：改成“闭合环路 + 网格支路”——
  - 外圈环路四面闭合（北 y20、南 y150、西 x22、东 x372）；
  - 三条南北纵路（x76 / x166 / x250）+ 行政楼前纵路（x206）；
  - 三条东西横路（y53 / y64 / y96）；
  - 中轴大道 12 格宽，正门两侧 X 广场四向接路。
  - 所有主路 4 格宽，互相正交、没有断头路；操场/体育区被环路完整包围。
- **沥青路面**：全部车行道换成沥青（深灰 + 细骨料 + 修补痕），两侧加混凝土路缘，长路段画中央虚线，校门口加斑马线，路口有井盖。
- **地图底色替换**：校园围墙内改为修剪过的草坪（三种草坪变体交替），围墙外仍是野草，形成“校内/校外”的质感差异。
- **建筑周边铺装**：每栋楼四周 2 格铺与建筑风格配套的硬质铺装——古典楼用石材、现代楼用清水混凝土、红砖/坡顶楼用红砖铺装，楼前场院自然过渡。
- **保留**：正门两侧 X 形步行广场（外圈环路 + 对角步道 + 中心广场）、中轴地标、4 个 U 形教学楼、体育区（2 篮球场 / 网球场 / 小池塘）。

## 已接通的系统

| 系统 | 文件 | 说明 |
| --- | --- | --- |
| 时间 / 季节 | `scripts/autoload/game_clock.gd` | 6:00 起床，02:00 强制入睡 |
| 世界 | `scripts/world/estate_map.gd` | 读 `estate.json` 生成地面、建筑、道路、操场、球场、池塘、花园、围墙、碰撞 |
| 像素素材 | `scripts/art/pixel_art.gd` | 程序化生成全部贴图，并支持 `assets/sprites/` 同名 PNG 覆盖 |
| 玩家 | `scripts/player/player.gd` | 移动、奔跑、互动 |
| NPC | `scripts/world/npc_student.gd` | 6 个沿路线走动的学生，可搭话 |
| HUD | `scripts/ui/hud.gd` | 日历、当前位置、提示条 |

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 奔跑 |
| 空格 | 和 NPC / 长椅 / 校牌 / 建筑互动 |
| T | 跳到清晨 |
| F1 | 显示/隐藏操作提示 |
